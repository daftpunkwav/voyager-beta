## 一、阻断级(建议立即修)

### F1. 贴图插入必然产生坏引用(前端)
`apps/web/src/components/note/NoteEditor.tsx:102-105`
bridge `cap()` 经 `wrap()` 返回信封 `{data:{asset_id,url,markdown}}`,代码判断
`'markdown' in res` 恒为 false,走 `String(res)` 兜底——粘贴/拖拽/工具栏三条
贴图路径全部插入 `![]([object Object])`,并被自动保存落库。
已核实:后端 `services/notes/assets.py:175-179` 返回值正确,被 gateway 信封包裹。
**修法**:取 `res.data.markdown ?? res.data.url`;根因是 `wrap` 以 `'data' in result`
嗅探信封,宜给 bridge 显式 unwrap 契约。

### F2. 深链/网格卡用摘要装编辑器,叠加自动保存会清空原文(前端)
`apps/web/src/pages/notes/NotesPage.tsx:112-120(深链)、384-388(网格卡)`
后端 `list_notes` 只回 `excerpt`(120 字窗口,无 content 字段;`services/notes/store.py:63-65`)。
深链路径把空串装入编辑器:用户敲一字 → 5 秒后自动保存以「空+一字」覆盖原文;
网格卡路径 `n.content` 为 undefined,`content.replace` 直接 TypeError。
实施时只修了侧栏 onSelect(`fetchNoteFull`),漏掉两处同根因路径。
**修法**:三处一律经 `fetchNoteFull` 取全文;搜索过滤改用 `excerpt`。

### F3. 「切笔记前 flush」不存在,dirty 编辑静默丢失(前端)
`apps/web/src/pages/notes/NotesPage.tsx:97-107`
effect cleanup 只 `clearTimeout` 不保存。场景推演:编辑 A(debounce 计时中)→
点列表 B → A 的编辑永久丢失,指示器却显示"已保存"。`handleNew`、回收站恢复、
深链切换同样不 flush;`beforeunload` 的异步 `doSave` 在 unload 前不保证发出。
**修法**:flush 提为 useCallback,所有 `startEditing` 调用点先 flush;关页改
`navigator.sendBeacon`。

### B1. 文档同名导入无去重 + 异步删除竞态误删(后端)
`services/sources/modules/doc/capabilities.py:124-127`
目标文件按 title 生成并直接覆写(doc 无任何去重;repo 有 `ON CONFLICT(url)` 对照,
`modules/repo/store.py:74`)。确定性事故序列:导入 A → 删除 A(文件删除入队)→
再导入同名 B(copy2 重建同路径)→ worker 处理旧删除任务删掉 B 的文件、解析置 failed。
单队列 FIFO 保证该顺序必然发生。
**修法**:落盘名加 uuid/内容哈希;或删除任务执行前校验路径仍属被删 doc。

## 三、建议(10 项)

1. **同服务内工具重复**:`_escape_like`(doc/web/repo 三份)、`valid_tag`(两份)在
   sources 服务内复制;`_UNSAFE_FILENAME_RE` 在 notes 内两份。跨服务"就近实现"是
   既定约定,同服务内重复是退化 → sources 内收敛一个 store 工具模块。
2. **排序设置失配**:`sources.sort.default` 的 choices(added/name/stars/updated)与
   聚合 `_SORT_KEYS`(added/updated/title)不匹配,name/stars 静默失效。
3. **inline 意图相反**:`sources/files.py:43` 的 `FileResponse(filename=...)` 默认
   attachment 下载,与"PDF 直接打开"注释矛盾 → 补 `content_disposition_type="inline"`。
4. **残留物**:`DocReader.tsx:232` 的 `void docId;`;`SourcesPage.tsx:133` 的
   `searchParams.get('import')==='stars' && null` 死代码;`PageReader.tsx:42` 把当前
   年份当文档元信息;`NoteEditor` 的 `variant='default'` 分支无调用方(死代码)。
5. **双 slug 实现不一致**:渲染端 github-slugger 对同页重复标题生成 `x`/`x-1`,
   TocPanel 的自制 slugify 永远得 `x` → 重复标题 TOC 全跳第一个。抽公共实现。
6. **migration 自带平行 DDL**:`migration.py` 重复 documents/webpages 建表,store 加
   NOT NULL 列时会漂移 → 从 store import schema 常量;顺删 `_now()`。
7. **测试伪断言**:`test_assets.py` 的 `hasattr(bus,'log')` 恒真、恒假的第一支
   disjunction;`deploy/tests/test_sources_universal.py` 的"agent 同权"测试可在完全
   没走 agent 路径时通过(404 静默回退 + 宽松状态码)。
8. **串行上传**:ImportCenter FilesPane 逐个 await,N 个大文件串行(量小可不动)。
9. **docSection 缓存缺口**:重解析后 `['docSection',...]` 不在任何失效集合,正文可能陈旧。
10. **Lightbox a11y**:无 focus trap / 初始聚焦 / body scroll lock(声明了 aria-modal)。
11. **docx 中文样式**:Heading 识别依赖英文样式名"Heading 1",中文 Word("标题 1")
    退化单章;按 `style_id` 判断更稳。
